先搞清楚：这个网页到底能碰哪些文件

这一节最重要，先看完再往下翻，能省掉一大堆误会。

请一定记住：网页不能自己扫描你电脑的硬盘。它看不见你桌面、下载文件夹、D 盘里的东西 —— 除非你亲手选一个文件夹、把文件导入进来。任何网页都做不到「一打开链接就自动读到你全部文件」，这是浏览器统一的安全规矩，不是这个工具的毛病。

所以，网页里能操作的，从头到尾只有这两类文件：

  • ① 页面自带的演示文件：7 个，来自 week5_planner 文件夹和一份 Word 报告，专门给你练手。
  • ② 你亲手导入进来的文件副本：导入 = 复制一份放进网页的文件库；你电脑上的原文件一个字节都不会被改动、移动或删除。
最容易误会的一点：你在网页里把文件「复制」到某个文件夹，那个文件夹是网页里的文件夹，不是你电脑上的真实文件夹。所以打开电脑里的文件夹，当然找不到它。要让结果真的出现在电脑里，必须做后面的「导出到电脑」或「写回到电脑」。
放心练：随便复制、移动、删除都行，练坏了点右上角「存储空间」里的「恢复演示库」，或者一路点「撤回」就好。

再记住三句话，就不会慌

这三点比任何操作步骤都重要。

① 不碰电脑原件

网页里整理的全是副本，你电脑里的原文件安然无恙。

② 每次都会先问你

真正执行前，会列出「要动哪些文件、怎么动」，还要你亲手再确认一次。

③ 做错了能撤回

复制、移动、删除都能「撤回」，撤回了还能「撤销撤回」改回来。

几个词，先说人话

看不懂的词在这里对一下，后面就不解释了。

词大白话意思
文件一个具体的东西，比如一份 Word 文档、一张图片、一个表格。
文件夹装文件的「抽屉」。文件夹里还能再放文件夹。
复制再弄一份一样的，原来那份还在。变成两份。
移动把文件换个地方放，原来位置就没有了。还是一份。
删除放进网页里的「回收站」，不是真的从电脑消失，随时能找回来。
批量一次勾选好几个文件（或一整个文件夹），一起做同一件事。
二次确认先给你看一遍「打算做什么」，你点头了才真的做。
撤回「刚才那步不算，退回去」。
撤销撤回「算了，还是按刚才那步来吧」，把撤回又改回去。
操作记录网页自动记的小本本：什么时候、对哪些文件、做了什么，能导出保存。
副本照着原文件另外做的一份。改副本，原件不受影响。
导入你亲手选一个文件夹，网页把里面的文件复制一份放进自己的文件库。只有导入进来的，网页才看得见、才能整理。
导出到电脑（ZIP）把整理好的文件打包成一个压缩包下载到电脑。解压后就是真实文件，可以放到任何位置。
写回到电脑你选一个真实文件夹，网页把整理好的文件写进去。同名文件直接覆盖，不会生成「文件 (1)」这类重复副本。
覆盖往同一个位置再写一次，旧内容被新内容替掉，文件还是那一个，不会多出一份。
本地存储空间副本存在你自己浏览器里占的硬盘地方。右上角「存储空间」能看占了多少、也能一键清掉。

第 1 步打开网页，先看懂页面

打开链接后，你会看到下面这个样子。认准四个地方就够了。

▲ 图 1：整理器首屏全貌

  • 上面一排数字：告诉你一共有多少文件、多少个文件夹、占多大地方。
  • 左边「位置」：像资源管理器的目录树，点一下就切换到那个文件夹。
  • 右边大表格：当前位置里有哪些文件，每行最前面有个小方框用来打勾。
  • 右上角四个按钮：撤回、撤销撤回、操作记录、存储空间；旁边还有「使用教程」（就是本页）。
看不懂也没关系：页面顶部有一段「先花 30 秒看懂这个页面」的说明，随时可以回去看。

第 2 步勾选你要整理的文件

在每行最前面的小方框里打勾。勾完，屏幕下方会自动浮出一条操作栏。

▲ 图 2：勾了两个文件，底部出现操作条

  • 只弄一个文件：勾它自己那一行就行。
  • 一次弄好几个：挨个打勾，想勾几个勾几个。
  • 整个文件夹一起弄：在左边位置树里选中那个文件夹，或用表格里的「全选」。
  • 勾错了：再点一下那个小方框，勾就取消了，不会有任何损失。
小提示：打勾只是「选中」，什么都没发生。真正的变化要等第 4 步点确认之后。

第 3 步选做什么、做去哪儿，然后看计划

在底部操作条上点「复制」「移动」或「删除」，接着会让你挑一个目标位置。

  • 点 复制：原文件留着，在目标位置多出一份。
  • 点 移动：文件搬到目标位置，原来位置就不显示了。
  • 点 删除：放进回收站，随时可以撤回找回来。

挑好位置、点「生成计划」，会弹出下面这张表。这是最关键的一步，请一定看一眼。

▲ 图 3：执行前的「操作计划」，逐条列清楚，还要再勾一次确认

  • 表里一行就是一个文件，写得清清楚楚：从哪儿 → 到哪儿 → 做什么。
  • 数量对不对、目标位置对不对，在这里一眼就能核对。
  • 发现不对？点「取消」，回去重新勾，这时候什么都还没做。
  • 确认没问题，勾上最下面那个「我已核对」的小方框，按钮才会亮起来。
为什么这么麻烦？就是为了防止手一抖删错东西。没有这一步，网页绝不会执行——这是硬规矩，不是建议。

第 4 步点确认，看结果

点「确认执行」后，会立刻告诉你这一批做得怎么样。

▲ 图 4：执行结果，成功 / 跳过 / 失败一目了然

  • 成功：正常做完了。
  • 跳过：目标位置已经有同名文件，网页没覆盖它（怕你弄丢东西）。
  • 失败：这一条没做成，原因会写出来，其他条不受影响。

做完回到主界面，文件列表和顶部数字会自己刷新，不用手动刷新网页。

第 5 步后悔了？撤回 / 撤销撤回 / 查记录

这是最让人安心的部分：复制、移动、删除，三种操作统统能退回去。

▲ 图 5：操作记录，每一步都留了痕

  • 撤回（右上角）：把最近一批操作退回去，比如刚复制的文件消失、刚删的文件回来。
  • 撤销撤回：撤回之后又后悔了，点它把那批操作重新做一遍。
  • 操作记录：右边会滑出一本流水账，哪天几点、动了哪些文件、什么结果，全在上面。
  • 导出记录：记录面板里可以下载成 JSON 或 CSV 存到自己电脑，长期留着备查。
删除也能撤回：删除是放进网页内的回收站，不是真的抹掉。撤回之后文件就回到原位置了。

第 6 步想看某个文件里写了啥？直接点开看

不用下载、不用另开软件，在这个网页里就能看内容。

  • 点文件名字，或者点这一行最右边的眼睛图标，就会弹出查看窗口。
  • 文本、代码、Markdown：直接显示文字，中文也不会乱码。
  • Word / PPT / Excel：自动把里面的文字抽出来给你看（图片和排版看不了）。
  • 图片、PDF：直接显示图 / 内嵌预览。
  • 压缩包：列出里面装了哪些文件。
  • 想拿原件：点查看窗口里的「下载此文件」，就会存到你电脑的下载文件夹。
看，不等于改。打开查看窗口只是读内容，不会动文件，也不会往电脑里写任何东西。

第 7 步把整理结果真正落实到电脑里（很关键）

前面所有复制、移动、删除，都只发生在网页里的副本上。想让电脑上真的变，必须再做这一步。

为什么我在电脑文件夹里找不到刚整理好的文件？因为它还在网页的文件库里，从没被写回你的硬盘。这是正常的，不是坏了 —— 照下面两种方式之一做一次就行。

方式一：导出到电脑（ZIP）—— 最稳，所有浏览器都能用

  • 勾选整理好的文件或文件夹 → 底部操作条点「导出到电脑（ZIP）」。
  • 会先弹出一张清单让你核对，勾上确认才会开始下载，同样有二次确认。
  • 下载得到一个压缩包，解压后里面的文件连着文件夹结构，就是电脑里实实在在的文件了，想放哪儿放哪儿。

方式二：写回到电脑 —— Chrome / Edge 可用，省掉手动解压

  • 勾选文件 → 点「写回到电脑」，亲手选一个电脑上的真实文件夹。
  • 弹窗里会逐条写清楚：哪些是「覆盖」已有文件、哪些是「新建」，以及各自的条数。
  • 同名就覆盖，绝不生成「文件 (1)」这种重复副本；路径也不会多套一层文件夹。
  • 默认勾着「只覆盖已存在的同名文件，不新建」，最保险：一个多余文件都不会冒出来。确实需要新增时，取消这个勾即可。
  • 勾上最下面的确认，才会真的写入。写多少、跳过多少，操作记录里都留痕。
关于「会不会越点越多」：不会。重复执行写回，文件数量不会增长 —— 同一位置永远是覆盖那一个文件。这一条是专门验过的。

第 8 步整理完，把导入的副本清掉，不占硬盘

导入的文件是以副本存在你自己浏览器里的，会占一点硬盘；关掉网页不会自动消失。

  • 点右上角「存储空间」，能清楚看到：一共占了多少、其中我导入的有几个、回收站里还留了多少。
  • 点「移除我导入的文件」→ 看清计划 → 勾选确认，才会真的清掉。
  • 清理会连回收站里的副本一起处理，并重建本地数据库，空间是真释放，不是假装删了。
  • 操作记录会保留，演示文件也还在，你电脑上的原文件更是分毫不动。
  • 想把整理出来的文件也一起清空、整个回到刚打开的样子，用「恢复演示库」。
建议顺序：导入 → 整理 → 先导出 / 写回（结果落到电脑）→ 最后再清空间。顺序反了，副本就没了。

想整理自己电脑里的文件？

可以，但要先明白浏览器的一条安全规矩，不然容易误会。

边界先说死：网页不能自己扫描你电脑的硬盘，也不能自动改动你桌面上的文件。它能碰的只有「页面自带的演示文件」和「你亲手导入进来的副本」，别的既看不见也碰不到。

完整流程四步，很好记：

  1. 导入：左下角点「从我的电脑导入文件夹」，选一个文件夹，网页把里面的文件复制一份进文件库（原文件不动）。Chrome / Edge 也可以用「挑一个电脑文件夹查看」先看清再勾选加入。
  2. 整理：按前面几步，在网页里复制、移动、删除、批量勾选、看计划、点确认。也可以直接点文件名查看内容。
  3. 落实到电脑：点「导出到电脑（ZIP）」下载解压，或点「写回到电脑」写进真实文件夹（同名覆盖、不产生重复副本）。少了这步，电脑上不会有任何变化。
  4. 清空间：右上角「存储空间」→「移除我导入的文件」，把副本清掉、释放硬盘。
一句话概括：它是「先导入副本 → 在网页里整理 → 再导出 / 写回」的整理台，不是直接改磁盘的搬家工。好处是：再怎么点，电脑里的原件都安然无恙。

常见问题

Q：为什么我在电脑的文件夹里，找不到网页里刚复制进去的文件？

因为网页整理的是副本，那个文件夹是网页里的文件夹，不是电脑上的真实文件夹。要落实到电脑，点「导出到电脑（ZIP）」下载解压，或点「写回到电脑」写进真实文件夹。这一步不做，电脑上不会变。

Q：网页能自动扫描、看到我电脑里的所有文件吗？

不能，任何网页都做不到。它只能操作页面自带的演示文件和你亲手导入进来的副本。没导入的文件，网页既看不见也碰不到。

Q：导入文件会占我硬盘吗？怎么清掉？

会占一点：副本存在你这个浏览器里（关掉网页不会自动消失）。点右上角「存储空间」能看占了多少，点「移除我导入的文件」、确认后就会连回收站副本一起清掉并重建本地数据库，空间是真释放。操作记录和演示文件会保留。

Q：写回会不会弄出一堆重复文件、越点越占地方？

不会。写回是同名覆盖，不会生成「文件 (1)」这类副本，路径也不会多套一层；默认还勾着「只覆盖已存在的同名文件，不新建」。连着写回两次，文件数不会增长。

Q：能直接在这个网页里看文件内容吗？

能。点文件名字或行尾的眼睛图标即可：文本 / 代码直接显示，Word / PPT / Excel 自动抽文字，图片和 PDF 直接预览，压缩包列清单。想拿原件点「下载此文件」。

Q：我关掉网页，之前整理的内容还在吗？

在。数据存在你这个浏览器里，下次打开还在。

Q：我把链接发给朋友，她会看到我整理的东西吗？

不会。每个人打开都是自己独立的一份，互相看不见，也不会互相影响。

Q：换了浏览器 / 换了电脑，内容还在吗？

不在，数据只留在原来的那个浏览器里。想带走就用「导出」下载成压缩包。

Q：清了浏览器缓存 / 用了无痕模式，会不会丢？

可能会。重要内容记得先导出保存；无痕窗口关掉就没了。

Q：点错了，已经执行了怎么办？

点右上角「撤回」。要是撤回了又想恢复，点「撤销撤回」。两下之内都能救回来。

Q：想从头再来一遍，怎么清空？

点右上角「存储空间」→「恢复演示库」，确认后回到刚打开时的干净状态（操作记录会保留）；也可以一直点「撤回」把操作退回去。

Q：为什么有的文件显示「跳过」？

目标位置已经有同名文件了，网页选择不覆盖，避免把旧文件弄丢。换个目标位置或先移走旧文件即可。

Q：手机上能打开吗？

能看、能点。不过「读取电脑文件夹」这类功能要电脑上的 Chrome / Edge 才方便用。

Q：想把这份教程存下来 / 打印成纸？

按 Ctrl + P，在打印窗口里选「另存为 PDF」或直接打印就行，已经排好版了。
